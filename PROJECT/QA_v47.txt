PRASANNAONE NONOGRAM v47 - DEEP QA REPORT
=======================================

CHANGE
------
- Added a dedicated circular Erase tool alongside Undo, Fill and Cross.
- The existing TOOL.ERASE model operation was already implemented; the
  omission was in the game interface. The new button now selects that mode.
- Erase clears both filled and crossed cells; repeating a visited cell during
  the same stroke is harmless and creates no inversion.
- Four circular controls fit portrait and compact layouts; landscape uses
  four vertically stacked targets.
- Service-worker cache advanced from v10 to v11 so clients fetch the new shell.
