INPUT BEHAVIOUR
---------------
A tap affects one cell. A drag chooses its axis from the first meaningful
movement: horizontal locks to the starting row; vertical locks to the starting
column. Diagonal drift is projected onto that one line. The starting cell
continues to determine the fixed fill/cross/erase intent for the full stroke.

DEPLOYMENT
----------
Upload ONLY the CONTENTS of GITHUB_PAGES_UPLOAD/ to the GitHub Pages root.
The separately supplied deployment ZIP is already packaged for that purpose.
For the repository's ZIP-import workflow, rename the deployment ZIP to
Nonogram.zip and upload it at repository root. The workflow removes stale site
files while preserving .github and then extracts the new payload.
